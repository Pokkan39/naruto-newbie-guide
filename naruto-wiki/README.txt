========================================
 火影忍者入坑教学 · 使用说明（小白版）
========================================

这是一个纯静态网站，一共就几个文件，双击也能打开。
下面告诉你三件事：怎么编辑、怎么发布、密码在哪改。


【一、怎么编辑内容】

1. 打开 edit.html（编辑页）。
   - 想在自己电脑上改：可以直接双击 edit.html。
   - 如果图片/视频显示不出来，用「本地小服务器」的方式打开（见文末小技巧）。

2. 输入密码进入（默认密码见第三节）。

3. 在目录树里操作：
   - ＋ 新增章节：加一个大分区。
   - 每个条目右边有按钮：
       ↑ ↓ = 上移 / 下移排序
       ＋   = 在它下面加一个子项（卡片）
       ✎    = 编辑这条内容
       🗑   = 删除
   - 编辑时可选三种类型：
       📝 文字：填标题 + 正文
       🖼 图片：点「选择文件」上传本地图片（自动存进文件，不用图床）
       🎬 视频：粘贴 B站 BV号 / 视频链接 / YouTube 链接都行，会自动预览

4. 改动会「自动保存到你这个浏览器」，刷新不丢。
   （注意：这个自动保存只在你自己电脑上，别人看不到，要发布见下一节。）
   存储用的是浏览器 IndexedDB（容量大，可放大量图片），
   上传图片会自动压缩，正常放几十张没问题。


【二、怎么发布给别人看】

网站默认显示的内容来自 content.json 这个文件。
你在编辑页改的东西，要变成大家能看到的，就三步：

1. 在编辑页点「⬇ 导出（发布用）」，会下载一个 content.json。
2. 用这个新文件，替换掉网站文件夹里旧的 content.json。
3. 把整个文件夹重新上传到你的托管（比如 GitHub Pages）。

—— 发布到 GitHub Pages（免费、有网址）——
1. 注册 github.com，新建一个仓库（Repository）。
2. 把这个文件夹里的所有文件传上去。
3. 仓库 Settings → Pages → 选 main 分支 → Save。
4. 等一两分钟，会给你一个网址（xxx.github.io/仓库名），发给别人即可。
以后更新内容：导出新的 content.json → 覆盖上传 → 网址自动更新。

—— 或者更简单：Netlify ——
打开 app.netlify.com，把整个文件夹直接拖进去，立刻得到一个网址。


【三、怎么改编辑密码】

打开 assets/editor.js，最上面这一行：
    const EDIT_PASSWORD = "114514";
把引号里的文字改成你想要的密码，保存即可。

注意：这个密码只是简单防路人，不是强加密（懂技术的人能看到）。
别放特别机密的东西就行。


【四、备份】
编辑页的「⬇ 导出」随时能存一份 content.json 当备份；
「⬆ 导入备份」可以把某个 content.json 重新读回来。


【小技巧：本地正确预览】
双击打开有时视频加载不出来。更稳的方式：
1. 在这个文件夹里打开命令行；
2. 运行： python -m http.server 8000
3. 浏览器访问： http://localhost:8000
   （编辑页是 http://localhost:8000/edit.html ）
