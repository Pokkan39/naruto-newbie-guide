# 火影忍者入坑教学 Wiki · 使用与发布说明

一个纯静态站点，仿参考站形态：目录树 + 卡片（文字/图片/视频），带密码保护的可视化编辑页，支持导入/导出 JSON。无需后端。

## 文件结构
```
naruto-wiki/
├── index.html        展示页（访客看的页面）
├── edit.html         编辑页（密码进入，可视化编辑）
├── content.json      网站默认内容（发布时替换的就是它）
├── assets/
│   ├── style.css     全站样式（火影橙黑主题）
│   ├── app.js        展示页逻辑 + 视频链接解析 + 公共函数
│   ├── editor.js     编辑页逻辑（增删改、上传、导入导出、密码）
│   └── logo.svg      站点图标（自绘忍者头带，无版权素材）
├── docs/             说明文档
└── README.txt        傻瓜版快速说明
```

## 编辑流程
1. 打开 `edit.html`，输入密码（默认 `naruto`）。
2. 目录树里操作：`＋新增章节` / 每条右侧 `↑↓`排序、`＋`加子项、`✎`编辑、`🗑`删除。
3. 节点分三类：
   - 文字：标题 + 正文
   - 图片：上传本地图片，自动转 base64 存入 JSON（无需图床）
   - 视频：粘贴 B站 BV号 / 视频链接 / YouTube 链接 / iframe 代码，自动识别并预览
4. 改动实时写入浏览器 IndexedDB（容量大，可存大量图片），刷新不丢（仅本机可见）。旧版 localStorage 数据会自动迁移。

## 发布流程（让别人看到）
展示页默认读取 `content.json`。发布 = 让线上的 `content.json` 变成你的最新内容：
1. 编辑页点 `⬇ 导出（发布用）`，下载新的 `content.json`。
2. 用它替换站点文件夹里的旧 `content.json`。
3. 重新上传整个文件夹到托管。

### 托管方式
- **GitHub Pages**：新建仓库 → 上传全部文件 → Settings → Pages → 选 main 分支 → 得到公开网址。更新内容时覆盖 `content.json` 再推送。
- **Netlify**：打开 app.netlify.com，把整个文件夹拖上去即可。

## 内容加载优先级
展示页加载顺序：浏览器本地保存（编辑预览）> `content.json`。
所以你在本机编辑时看到的是本地最新版；别人访问看到的是线上的 `content.json`。

## 修改编辑密码
编辑 `assets/editor.js` 顶部：
```js
const EDIT_PASSWORD = "114514";
```
改引号内文字即可。注意这是前端简单口令，仅防路人，非强加密，勿放机密内容。

## 视频链接支持格式
- B站 BV 号：`BV1xxxxxxx`
- B站视频页链接（含 BV/av）
- YouTube：`youtu.be/xxx`、`youtube.com/watch?v=xxx`、`embed` 链接
- 任意 `https://` 嵌入链接或完整 `<iframe>` 代码

## 本地预览建议
双击打开偶尔加载不全，推荐起本地服务：
```
python -m http.server 8000
```
访问 `http://localhost:8000`（编辑页 `/edit.html`）。
